## 1. 术语

- **基础概率**：未触发保底时单抽的出金率。
- **综合概率**：含保底机制后的长期平均出金率，官方公示。
- **软保底**：出金率在硬保底前开始陡增的区间，具体曲线官方通常不公布。
- **硬保底**：到达该抽数必出金。
- **小保底**：保底周期内第一个金，可能歪常驻。
- **大保底**：小保底歪后，下一金必为 UP。
- **定轨**：武器池机制，命定值积满后下一金必为选定武器。

## 2. 限定角色池（原神 / 绝区零同构）

| 项 | 数值 |
|---|---|
| 基础概率 | 0.6% |
| 综合概率 | 1.6% |
| 硬保底 | 90 抽 |
| 软保底 | 约第 74 抽起（绝区零为每抽 +6%；原神官方未公布曲线，社区实测一致） |
| 首个金 UP 概率 | 50% |
| 歪后 | 下一金必 UP |
| 单个金期望 | 62.3 抽（官方口径 62.5） |
| 限定 UP 期望 | 93.4 抽，最坏 180 |

原神额外机制「捕获明光」（仅角色池，绝区零无此机制）：在小保底 50-50 判定失败、本该歪常驻时，有概率触发捕获明光，将该金强制逆转为期 UP，视为正常 UP 出金并消耗保底。

- 基础触发率 0.018%；含此机制后小保底综合 UP 率为 55%（标准机制为 50%）。
- 连续 3 次靠大保底（第二次出金）才拿到 UP 后，下一次小保底必触发。
- 各状态触发概率随连续大保底次数递增；除官方公示的首尾值外，中间概率为标定到 55% 的推断值（见脚本 `CR_PROBS`）。
- 计入后稳态限定 UP 期望约 90.3 抽，最坏仍为 180。

## 6. 信息渠道分级

**第一层：官方一手（最终依据）**

- 游戏内公告与卡池详情：概率、技能、定轨的最终文本。
- 版本前瞻直播：版本上线前约 1–2 周，多平台同步，公布新角色/卡池/活动并发兑换码。
- 官方角色预告（drip marketing）：新角色提前约一版本发布。
- 米游社（国内）/ HoYoLAB（海外）、官网新闻、官方微博与 B 站账号。

**第二层：数据与攻略社区（整理与测算）**

- 米游社攻略区、B 站攻略：配队、机制、抽数实测。
- 数据站：GachaHaven、gachatracker（复刻预测）、Timesaver（保底机制）、zzz-poly-cal、chjiya 攻略站。
- NGA 等论坛：部分板块明确禁止转载未证实爆料，引用时注意。

**第三层：爆料与泄露（仅预规划）**

- 测试服解包与录屏：信息具体但反复修订，不能当最终值。
- 舅舅党文字爆料：多为单源，可信度最低。

**甄别原则**：多源交叉、有截图或数据支撑者优先；测试服内容以官方前瞻为最终裁决；未官宣信息不用于投入资源的最终决策。

## 7. 数据口径与复核

- 复核基准日期：2026-11。
- 官方公示项：基础/综合概率、硬保底、UP 概率、捕获明光基础触发率与三连歪规则，可在游戏内详情与官方概率公示页核对。
- 建模推断项：软保底曲线（原神官方未公布，社区实测拟合）、捕获明光中间状态概率（标定到综合 UP 率 55%）、各分位与期望（由脚本计算）。
- 复核方式：通过版本前瞻与官方概率公示页确认规则是否调整；规则若变动，重跑脚本并更新本文件。
