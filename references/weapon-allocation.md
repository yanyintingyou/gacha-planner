# 武器存量、替代与分配

在决定是否抽武器前，先盘点存量与免费替代，并解决有限武器在角色间的分配。具体武器与角色的匹配度当期通过网络核实，本文件只给分析框架。

## 1. 武器匹配度的判断维度

判断一把武器与角色是否匹配，按以下顺序：

1. 副词条定位：副词条类型（攻击/防御/生命百分比、暴击、暴伤、精通、充能、物理伤害）直接决定武器的服务对象，是第一信号。输出角色匹配暴击/暴伤武器，生命 C 或盾辅匹配生命百分比，依此类推。
2. 词条是否溢出：结合角色自身增益与圣遗物，判断副词条是否会溢出（如暴击武器配高暴击角色导致暴击溢出），溢出部分不产生收益，匹配度下降。
3. 白值与副词条权衡：基础攻击与副词条此消彼长；角色高暴伤时高白值更值钱，低暴伤时副词条权重更高。
4. 特效契合度：武器特效是否对齐角色的输出方式、站场时长、反应类型、轴长；特效有触发条件时，确认角色能否稳定满足。
5. 通用性：特效是否绑定特定机制，泛用武器可在多角色间流转，绑定机制的武器适用面窄。

匹配度当期通过攻略与实测核实，量化为相对某参照的百分比，不凭印象判断。

## 2. 是否值得抽某武器

按“先替代、后差距、再成本”决策：

1. 先确认存量与免费替代（见第 3 节），存在可用替代时不进入抽卡。
2. 量化专武相对替代的提升幅度，区分两类：
   - 输出向：只是数值百分比提升，按幅度判断是否值得抽数。
   - 机制向：补足角色机制缺口（如满足关键阈值、解锁关键触发），不可替代时价值更高。
3. 把提升幅度对照抽数成本与角色使用预期：角色上场率低、即将下岗，或提升幅度小于资源的其他用途，就不抽。
4. 武器池口径：双 UP 池区分“任意一把 UP”与“特定一把（定轨）”，成本不同；定轨不跨期继承，规划特定武器取特定口径。

## 3. 存量与免费替代优先

下池前按顺序排查：

1. 账号已有武器：是否有可直接使用或重新分配的存量五星。
2. 免费获取渠道：活动、锻造、世界任务、商店兑换等可获取的武器，确认获取成本与精炼上限。
3. 量化替代差距：把免费或存量替代相对专武的强度量化，差距小则用替代、把抽数留给硬需求。
4. 精炼与白板：部分免费武器高精炼后可接近低精炼五星；注意白板武器（无有效特效）的适用条件。

## 4. 有限武器在角色间的分配

当多角色争夺有限武器时，按边际收益分配，而非平均或按角色强度：

1. 列候选配对：对每把武器，列出所有可装备且匹配的角色，量化各组合的相对收益。
2. 算边际收益：一把武器给某角色的增量 = 装备后相对其当前替代的提升，再按该角色在队伍中的输出占比折算全队收益。
3. 全局最优配对：在武器与角色的配对矩阵上，选择全队总收益最大的分配，避免把高匹配武器给边际提升小的角色。
4. 考虑轴与复用：同一把武器若被多队需要，确认这些队伍是否同时上场；错峰使用可减少抽取需求。
5. 分配结果反哺抽卡：分配后仍存在的真实缺口才列为武器抽取目标，已被存量覆盖的不重复抽。

## 5. 数据口径与复核

- 复核基准日期：2026-11。
- 稳定项：匹配度判断维度、决策顺序、武器池口径关系；具体武器数值、匹配百分比、角色阈值为当期核实项。
- 复核方式：版本攻略与实测确认匹配度与替代差距，官方概率页确认武器池规则；规则调整时更新本文件。
